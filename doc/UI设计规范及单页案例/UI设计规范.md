# 平台基础 UI 设计规范（通用）

> 版本：v1.3
> 定位：平台级**通用、与具体业务无关**的 UI 设计规范，供所有业务系统复用。
> 适用：Web 应用（vue3 + vite + TypeScript 技术栈，Element Plus 组件库）。
> 说明：本规范不涉及任何具体业务功能与页面，仅定义通用视觉语言、设计令牌、通用组件形态及落地约定。
> 视觉基调：**商务质感 · 强化玻璃拟态（Glassmorphism）**，主色为**商务淡蓝（Business Blue）**、辅色为**天青蓝（Sky）**。

---

## 1. 设计目标与价值观

- **清晰**：信息层级分明，主线一眼可读，避免歧义。
- **高效**：常用操作前置、就近可达，减少点击层级。
- **克制**：视觉元素克制，留白充足，避免炫技性装饰。
- **一致**：全平台统一令牌与组件，保证跨页面一致性。
- **包容**：满足可访问性（a11y），键盘可用、对比度达标、尊重系统动效偏好。

---

## 2. 设计令牌（Design Tokens）

> 样式一律基于令牌，禁止在业务代码中硬编码色值 / 字号 / 间距，便于换肤与多主题适配。

### 2.1 语义色板

> 主色为**商务淡蓝**，辅色为**天青蓝**，二者构成「蓝 → 天蓝」的同色系品牌渐变，克制、可信、偏商务；状态色采用明度更高、更现代的取值。

| `color.primary.hover` | `#2563EB` | `#93C5FD` | 主色悬停 |
| `color.primary.active` | `#1D4ED8` | `#3B82F6` | 主色按下 |
| `color.primary.bg` | `#EFF6FF` | `rgba(59,130,246,.18)` | 主色浅底（标签/选中背景） |
| `color.accent` | `#0EA5E9` | `#38BDF8` | 辅色 · 渐变终点 · 强调 |
| `color.success` | `#10B981` | `#34D399` | 成功、在线 |
| `color.warning` | `#F59E0B` | `#FBBF24` | 警告 |
| `color.danger` | `#EF4444` | `#F87171` | 错误、删除、危险 |
| `color.info` | `#64748B` | `#94A3B8` | 中性提示 |

**品牌渐变**：`linear-gradient(135deg, #3B82F6 0%, #0EA5E9 100%)`，用于主按钮、品牌标识、Banner 等视觉主位；深色模式可提亮至 `#60A5FA → #38BDF8`。

### 2.2 中性色 / 表面（含玻璃层）

> 页面底色叠**径向光晕**（blue / sky 低透明度）为玻璃层提供可模糊的背景内容 —— 光晕必须有足够强度，否则玻璃无内容可模糊、退化为半透明块。密集数据区（表格、表单）使用实体表面保证可读性，视觉主位（卡片、导航、浮层）使用玻璃表面。

| 令牌 | 浅色模式 | 深色模式 | 用途 |

### 2.4 间距（spacing）

基准 `4px`，栅格：`4 8 12 16 20 24 32 40 48`。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `space.xs` | 4px | 图标文字间距、标签内间距 |
| `space.sm` | 8px | 紧凑元素间距 |
| `space.md` | 16px | 组件内间距、卡片内边距 |
| `space.lg` | 24px | 区块间距、页面左右边距 |
| `space.xl` | 32px | 大区块、页面顶部留白 |

### 2.5 圆角与边框

> 现代 UI 采用**较大的圆角**营造柔和科技感；小控件 8px、卡片 12px、大面板 16–24px。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `radius.sm` | 8px | 按钮、输入框、标签 |
| `radius.md` | 12px | 卡片、工具条、下拉浮层 |
| `radius.lg` | 16px | 大弹层、抽屉 |
| `radius.xl` | 24px | 大玻璃面板、Banner |
| `radius.full` | 999px | 头像、徽标、胶囊 |
| `border.width` | 1px | 统一细边框（低透明度） |

### 2.6 阴影

> 采用**多层叠加 + 彩色发光**的现代阴影：常规阴影用两层（近距柔化 + 远距扩散）提升真实感；主操作元素额外叠加蓝色发光，形成克制而明确的焦点。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `shadow.sm` | `0 1px 2px rgba(15,23,42,.04), 0 1px 3px rgba(15,23,42,.06)` | 常规 |
| `shadow.md` | `0 4px 16px rgba(15,23,42,.08), 0 2px 6px rgba(15,23,42,.04)` | 悬浮、浮层 |
| `shadow.lg` | `0 16px 48px rgba(15,23,42,.14), 0 4px 16px rgba(15,23,42,.06)` | 大弹层 / 抽屉 |
| `shadow.glow` | `0 8px 32px rgba(59,130,246,.35)` | 主按钮 / 品牌元素发光 |

> 商务场景下发光宜**收敛**：`shadow.glow` 只用于主按钮与品牌标识，不用于普通卡片；玻璃表面的阴影保持中性灰蓝，避免整页泛蓝。

### 2.7 动效

> 采用**现代减速曲线**：常规交互用 `expo-out` 手感（起步快、收尾稳），强调型入场用带轻微回弹的 `spring`。

| 令牌 | 值 | 适用 |
| --- | --- | --- |
| `motion.fast` | 120ms | 细粒度状态（hover / active） |
| `motion.base` | 200ms | 默认过渡 |
| `motion.slow` | 320ms | 浮层、布局、抽屉过渡 |
| `motion.ease` | `cubic-bezier(.32,.72,0,1)` | 统一缓动（expo-out） |
| `motion.spring` | `cubic-bezier(.34,1.56,.64,1)` | 强调入场（轻微回弹） |

> 遵循 `prefers-reduced-motion`：系统关闭动效时禁用非必要动画。

### 2.8 Z-index 层级

> 所有浮层、弹窗、固定栏统一引用以下令牌，禁止散落硬编码 `z-index`，避免层叠冲突与"谁压谁"的随机性。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `z.base` | `0` | 普通文档流内容 |
| `z.dropdown` | `1000` | 下拉菜单、选择器浮层、Popover、Tooltip |
| `z.sticky` | `1100` | 吸顶表头、固定工具条、吸底操作栏 |
| `z.drawer` | `1200` | 抽屉 |
| `z.modal` | `1300` | 对话框 Dialog |
| `z.message` | `1400` | Toast / Message / Notification（最高，确保不被遮挡） |

- 同层组件后渲染者在上；如需显式控制，仅在上述令牌范围内调整。
- 全屏遮罩统一使用 `z.modal - 1` 作为遮罩层，弹窗本体使用 `z.modal`。

| --- | --- | --- | --- |

| 2 | `#10B981` | `#34D399` | 正向 / 达成 |
| 3 | `#F59E0B` | `#FBBF24` | 提示 / 警戒 |
| 4 | `#0EA5E9` | `#38BDF8` | 辅助系列（天蓝） |

- 趋势型图表（涨跌）遵循中国证券市场惯例：**涨为红 `#EF4444`、跌为绿 `#10B981`**，与上述系列色板区分使用。

### 2.10 玻璃拟态（Glassmorphism）· 强化版

> 本规范的视觉主基调。玻璃表面用于**视觉主位**（卡片、导航、浮层、Banner），密集数据区仍用实体表面以保证可读性。
> 强化原则：**底色更透、模糊更强、饱和度更高、棱边更亮** —— 四者需同步调整，只调其中一项会得到"发灰的塑料"而非"玻璃"。

**玻璃四要素：**

| 要素 | 取值 | 说明 |
| --- | --- | --- |
| 半透明底 | `glass.bg` | 浅 `rgba(255,255,255,.52)` / 深 `rgba(30,41,59,.42)`；不透明度**不超过 .55**，过高则失去玻璃感 |
| 背景模糊 | `backdrop-filter: blur(24px) saturate(200%)` | 对应 `glass.blur` + `glass.saturate`；强玻璃用 `glass.blur-strong`（32px） |
| 外高光棱边 | `border: 1px solid glass.border` | 浅色用 `rgba(255,255,255,.78)` 白棱边，深色用 `rgba(255,255,255,.15)` |
| 内高光 | `box-shadow: inset 0 1px 0 glass.highlight` | 顶部 1px 白色内阴影，模拟光线打在玻璃上表面，是"玻璃厚度感"的关键 |

**标准玻璃卡片：**

```css
.glass {
  background: var(--wb-glass-bg);
  backdrop-filter: blur(var(--wb-glass-blur)) saturate(var(--wb-glass-saturate));
  -webkit-backdrop-filter: blur(var(--wb-glass-blur)) saturate(var(--wb-glass-saturate));
  border: 1px solid var(--wb-glass-border);
  border-radius: var(--wb-radius-md);
  box-shadow: inset 0 1px 0 var(--wb-glass-highlight), var(--wb-shadow-md);
}
```

**三档玻璃厚度：**

| 档位 | 模糊 | 适用 |
| --- | --- | --- |
| 轻 | `blur(8–12px)` | Banner 内嵌标签、图片角标 |
| 标准 | `blur(24px)` | 卡片、侧栏、工具条、TabBar |
| 强 | `blur(32px)` | 顶栏、对话框、抽屉（覆盖内容多、需强隔离） |

**使用约束：**

- 玻璃必须叠在**有内容或光晕的底色**之上，纯色背景下玻璃退化为半透明块、观感廉价。**背景光晕是玻璃的前置条件**，见 2.2 的光晕参考值。
- 单页面玻璃层级不超过 2 层（避免模糊叠加导致性能下降与视觉浑浊）。
- 玻璃表面上的文本必须满足对比度 ≥ 4.5:1 —— 因底色已降到 .52 透明度，正文应使用 `color.text` / `color.text-2`，**禁止在玻璃上使用 `color.text-3` 承载关键信息**。
- `backdrop-filter` 有性能开销：大面积常驻玻璃（顶栏、侧栏）应避免内部再嵌套玻璃。
- 浏览器不支持 `backdrop-filter` 时优雅降级为 `color.surface` 实体底色。

## 3. 布局基础

### 3.1 栅格与断点

- 12 列栅格；页面左右边距 24px；内容区最大宽度视场景而定。
- 断点：`≥1024px`（宽屏多栏）、`768–1023px`（中屏收拢次要栏）、`<768px`（移动单栏）。

### 3.2 常用页面骨架

- 通用型：`顶栏 + 内容区`，或 `侧栏 + 内容区`。
- 信息密集型：`多栏栅格`（两栏 / 三栏），具体拆分由业务文档定义。
- **玻璃层级约定**：顶栏、侧栏、浮动工具条使用**玻璃表面**（吸顶/常驻时模糊下层内容滚动，强化空间感）；表格、表单等密集数据区使用**实体表面**。二者不叠加超过 2 层。
- **玻璃厚度分工**：顶栏 / 对话框 / 抽屉用**强玻璃**（`blur 32px`），卡片 / 侧栏 / 工具条 / TabBar 用**标准玻璃**（`blur 24px`），Banner 内嵌标签用**轻玻璃**（`blur 8–12px`）。

### 3.3 响应式行为

| 断点 | 宽度区间 | 布局策略 | 典型场景 |
| --- | --- | --- | --- |
| `lg` | ≥ 1024px | 多栏并列、侧栏常驻、表格完整列 | 桌面端 |
| `md` | 768–1023px | 次要栏折叠为抽屉、表格保留关键列 | 平板 / 小屏笔记本 |
| `sm` | < 768px | 单栏堆叠、侧栏收起为汉堡菜单、操作栏吸底 | 移动端 |

- 响应式优先"渐进增强"：以 `md` 为基线设计，向 `lg` 增强、向 `sm` 降级。
- 表格在窄屏优先隐藏次要列（而非横向滚动），并提供"列设置"入口。
- 工具栏与筛选区在 `sm` 折叠为可展开面板，避免首屏被操作占满。

## 4. 通用组件规范

> 定义各组件的**通用形态**；具体页面的业务文案与组合见各业务 UI 文档，引用本规范令牌。

### 4.1 按钮 Button

| 型态 | 说明 |
| --- | --- |
| 主按钮 primary | 填充主色、白色文字，用于主操作 |
| 次按钮 default | 表面底色 + 边框，用于次要操作 |
| 文本按钮 text | 无边框，用于行内 / 轻操作 |
| 危险按钮 danger | 危险语义，用于删除类操作 |
| 链接 link | 文本链接样式 |

- 尺寸：`md`（默认 32px 高）、`sm`（28px）、`lg`（40px）。
- 状态：默认 / hover / active / loading / disabled。
- 主按钮采用**品牌渐变**（`linear-gradient(135deg,#3B82F6,#0EA5E9)`）+ `shadow.glow` 发光，hover 时略提亮、发光增强；次按钮用玻璃/实体底 + 低透明边框。
- 同组按钮间距 8px。
- 圆角统一 `radius.sm`（8px）。

### 4.2 输入与表单

- 输入框：默认高 32px；focus 显示主色聚焦环（`rgba(59,130,246,.22)`）。
- 状态：默认 / hover / focus / disabled / error，error 需辅助错误文案。
- 表单：标签左对齐（移动端顶对齐）；必填项 `*` 标记；校验错误红色边框 + 下方错误文字。
- 高度大表单（登录）可用 40px。

### 4.3 选择类控件

- Select / 单选 / 多选 / Switch，风格一致，支持键盘操作；下拉用浮层，可含搜索过滤（可选）。

### 4.4 表格

> 表格属于**密集数据区**，使用**实体表面**（`color.surface`）而非玻璃，以保证文字对比度与扫描效率。

| 项 | 值 |
| --- | --- |
| 表头 | 背景 `color.striping`，字重 600，`type.tiny` 字号 + 字距 `0.02em` |
| 行高 | 48px（紧凑 40px） |
| 斑马纹 | 可选；悬浮行高亮 `color.striping` |
| 操作列 | 固定右侧，文字按钮 |
| 批量操作 | 勾选后顶部/底部工具条承载（可用主色浅底） |
| 分页 | 右下角，每页默认 20，可选 10/20/50/100 |

### 4.5 对话框 / 抽屉

- 用于确认或编辑任务；标题 + 正文 + 底部操作区（取消 + 主操作）。
- 圆角 `radius.lg`（16px）；对话框与抽屉使用**强玻璃**（`glass.blur-strong`，32px）或实体表面（视背景复杂度），配合 `shadow.lg`。
- 支持 Escape / 遮罩关闭；遮罩点击关闭需谨慎。
- 遮罩统一 `rgba(15,23,42,.45)`（浅）/ `rgba(0,0,0,.6)`（深），可叠加轻量 `backdrop-filter: blur(4px)`。

### 4.6 反馈（Toast / Notification / Message）

- 短暂反馈用 Toast（2~3s 自动消失）；重要事件用 Notification（可手动关闭）。
- 四类语义：success / error / warning / info，带对应色图标。

### 4.7 辅助组件

| 组件 | 规范 |
| --- | --- |
| Badge | 计数角标，danger 红点 / 胶囊计数 |
| Tag | 状态标签：success/warning/danger/info/primary 变体 |
| Avatar | 圆形或圆角；图片失败回退姓名首字 + `color.primary.bg` |
| Tooltip / Popover | 浮层实现，文案简短 |
| Empty | 居中图标/插画 + 说明 + 可选操作按钮 |
| Skeleton | 页面/区块加载优先骨架屏 |
| Progress | 进度条，颜色随阈值变化（<60% 绿 / <80% 黄 / ≥80% 红） |

## 5. 图标系统

> **硬性规定：界面图标禁止使用 emoji。** emoji 是彩色位图字体，跨系统（Windows / macOS / Android / iOS）渲染差异极大、无法控制描边粗细与颜色、无法与文本基线精确对齐，观感业余且不可控。所有界面图标必须使用**线性 SVG 图标**。

### 5.1 图标规格

| 项 | 规格 |
| --- | --- |
| 风格 | 线性（outline），描边 `1.5px` |
| 画布 | `24 × 24` viewBox，四周留 2px 安全边距 |
| 线端 / 拐角 | `stroke-linecap: round` + `stroke-linejoin: round` |
| 取色 | `stroke="currentColor"`，颜色随文字自动继承 |
| 尺寸阶梯 | `16px`（行内/小控件）、`20px`（导航/工具条）、`24px`（功能位）、`32px`（空状态/引导） |
| 填充 | 默认无填充（`fill: none`）；仅"激活态"可用同色 10% 透明度轻填充 |

### 5.2 推荐图标库

| 库 | 说明 |
| --- | --- |
| **Lucide** | 首选。开源 MIT，1000+ 线性图标，1.5–2px 描边，与 Element Plus 气质契合 |
| **Tabler Icons** | 备选。风格接近，图标量更大 |
| **自定义 SVG** | 业务专有图标，须严格遵循 5.1 规格 |

> Element Plus Icons 可作为补充，但其描边偏细（1px），与 Lucide 混用需统一为 1.5px。

### 5.3 使用规范

- **不混用风格**：同一界面禁止线性图标与面性（filled）图标混用。
- **尺寸对齐**：图标与相邻文字垂直居中；16px 图标配 14px 文字，20px 图标配 16px 文字。
- **图标按钮必须带 `aria-label`**（可访问性要求，见第 6 章）。
- **不滥用图标**：图标用于辅助识别，不替代文字；关键操作必须"图标 + 文字"。
- **插画**：空状态 / 引导 / 登录视觉使用统一风格插画（扁平、几何化、商务淡蓝主色系），与线性图标形成层级区分，不自造混杂风格。

### 5.4 图标落地方式

```vue
<!-- 推荐：内联 SVG，颜色随 currentColor 继承 -->
<svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor"
     stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
  <path d="M21 21l-4.35-4.35M11 19a8 8 0 100-16 8 8 0 000 16z"/>
</svg>
```

```css
.icon { width: 16px; height: 16px; flex-shrink: 0; }
.icon--nav { width: 20px; height: 20px; }
.icon--feature { width: 24px; height: 24px; }
```

> 图标统一封装为 `<AppIcon name="search" />` 组件，集中管理路径数据，禁止在业务代码中散落大段 SVG 路径。

## 6. 可访问性（a11y）

- **对比度**：正文与背景 ≥ 4.5:1；大字 / 大图标 ≥ 3:1。
- **键盘**：全功能可键盘操作；清晰的 `:focus-visible` 焦点环；支持 `Esc` 关闭浮层、`Enter` 提交。
- **语义化**：合理使用 header / nav / main / section / article / aside / footer，配合 ARIA。
- **ARIA**：弹窗 `role=dialog`；实时通知 `aria-live=polite`；图标按钮带 `aria-label`。
- **动效**：尊重 `prefers-reduced-motion`。
- **状态不只靠颜色**：组合文字 / 图标 / 样式表达状态。

---

## 7. 主题与换肤

- 内置 浅色 / 深色 两套主题（自动跟随系统，可手动覆盖并持久化）。
- 主题通过令牌（CSS 变量）实现，业务组件不得写死颜色。
- **玻璃与光晕随主题联动**：浅色玻璃为白系半透明，深色玻璃为深蓝灰半透明；页面背景光晕在深色下需降低透明度、提升模糊感，避免眩光。
- 预留品牌色集中替换能力：替换 `color.primary` / `color.accent` 两个令牌即可整体换色（小程序案例即以此切换为微信绿）。

## 8. 内容与文案规范

> 通用文案口径；具体业务文案由各业务 UI 文档定义，但须遵循以下原则。

- **简洁直接**：按钮、链接以动词开头，2–6 字优先（"保存"而非"进行保存操作"）。
- **主操作明确**：确认类按钮写具体动作（"删除""提交"），避免笼统的"确定"；危险操作按钮需带对象（"删除选中项"）。
- **人称一致**：面向用户的文案统一用「你」，避免「您 / 你 / 亲」混用。
- **反馈具体**：成功提示写清"做了什么"（"已保存""已删除 3 项"），避免无信息的"操作成功"。
- **空状态可行动**：空状态文案须说明现状 + 给出下一步动作（"暂无数据，点击「新建」添加"）。
- **数字与单位**：金额带货币符号（¥）、数量带单位、时间用相对表述（"3 分钟前"）或标准格式（`YYYY-MM-DD HH:mm`）。
- **避免歧义与歧义词**：不使用"可能 / 也许"等模糊词表述确定结果；状态词统一（"启用 / 停用"而非"开 / 关"）。

## 9. 国际化（i18n）

- 所有用户可见文本经 i18n key 取用，禁止在模板中硬编码中文。
- 文案 key 命名：`模块.场景.键`（如 `common.button.save`、`user.list.empty`），全小写、点分。
- 文案预留扩展：英文文案普遍比中文长 20%–40%，按钮与标签容器须留弹性宽度（不固定 `width`，必要时 `max-width` + 省略号）。
- 日期 / 时间 / 数字格式随 locale 切换；货币显示随地区。
- 当前版本以简体中文为基线，预留多语言接入结构；RTL（从右到左）布局暂不在范围内，但令牌须以逻辑属性（`margin-inline` 等）表达，便于未来扩展。

## 10. Element Plus 主题定制与令牌映射

> 本规范令牌须在 Element Plus 主题系统中落地，保证组件库视觉与平台令牌一致。

### 10.1 主题变量映射

| 平台令牌 | Element Plus 变量 |
| --- | --- |
| `color.primary` | `--el-color-primary` |
| `color.success` | `--el-color-success` |
| `color.warning` | `--el-color-warning` |
| `color.danger` | `--el-color-danger` |
| `color.info` | `--el-color-info` |
| `color.border` | `--el-border-color` |
| `color.text` | `--el-text-color-primary` |
| `color.text-2` | `--el-text-color-regular` |
| `color.text-3` | `--el-text-color-secondary` |
| `color.bg` | `--el-bg-color`（页面层）/ `--el-fill-color-blank` |
| `radius.md` | `--el-border-radius-base` |

### 10.2 落地方式

- 通过 **CSS 变量覆盖**（推荐）：在全局样式表中定义 `:root` 与 `[data-theme="dark"]` 两套令牌，并将上述 Element Plus 变量指向平台令牌，避免运行时开销。
- 深色模式切换：在 `<html>` 上切换 `data-theme` 属性，CSS 变量自动联动，业务侧无需感知。
- 组件级定制仅在确有必要时使用 `:deep()`，且只覆盖本规范未涵盖的局部样式，不破坏令牌体系。

## 11. 代码约定与命名规范

- **令牌文件**：统一置于 `src/styles/tokens/`，按 `colors.ts`、`typography.ts`、`spacing.ts`、`motion.ts`、`z-index.ts` 拆分，导出 TS 常量供 JS 侧引用，并同步生成 CSS 变量。
- **CSS 变量命名**：小写连字符，前缀 `--wb-`（如 `--wb-color-primary`、`--wb-space-md`），避免与 Element Plus `--el-` 前缀冲突。
- **语义化优先**：业务组件使用语义令牌（`--wb-color-danger`）而非原始色值（`--wb-color-red-500`），便于后续换肤。
- **组件目录**：通用业务组件置于 `src/components/`，按 `组件名/` 目录组织（`index.vue` + 同名 `*.ts`）；页面组件置于 `src/views/`。
- **禁止硬编码**：色值、字号、间距、圆角、阴影、z-index 一律引用令牌；Code Review 须拦截硬编码值。
- **暗色适配自检**：每处自定义背景 / 文字须同时声明浅 / 深两套取值或引用令牌，禁止只写浅色。
