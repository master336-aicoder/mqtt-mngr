1设计目标与价值观

平台级通用、与具体业务无关的 UI 设计语言。五个关键词定义一切取舍。

清晰

信息层级分明，主线一眼可读

高效

常用操作前置，减少点击层级

克制

留白充足，避免炫技性装饰

一致

统一令牌与组件，跨页面一致

包容

键盘可用、对比度达标、尊重动效偏好

2.10 玻璃拟态（Glassmorphism）· 强化版

玻璃四要素

半透明底（不透明度 ≤ .55）+ 背景模糊 24px + 饱和度增益 200% + 内外高光棱边。四者需同步调整 —— 只调其中一项，得到的是"发灰的塑料"而非玻璃。

玻璃表面

blur(24px) · saturate(200%) · inset 高光

本页卡片 / 顶栏 / 侧栏均使用玻璃表面 · 表格与表单使用实体表面保证可读性 · 单页玻璃层级 ≤ 2 · 厚度三档：轻 8–12px / 标准 24px / 强 32px（顶栏 · 对话框）

6可访问性（a11y）

对比度

正文与背景 ≥ 4.5:1 · 大字 / 大图标 ≥ 3:1 · 玻璃表面上的文本同样须达标

键盘

全功能可键盘操作 · :focus-visible 焦点环 · Esc 关浮层 · Enter 提交

语义化

header / nav / main / section / aside / footer + ARIA

状态不只靠颜色

组合文字 / 图标 / 样式 · 弹窗 role=dialog · 通知 aria-live=polite

7主题与换肤

点击右上角切换。玻璃与光晕随主题联动；替换 color.primary / color.accent 两个令牌即可整体换色。

8内容与文案规范

推荐
按钮：「保存」「删除选中项」
反馈：「已保存」「已删除 3 项」
空状态：「暂无数据，点击「新建」添加」
人称：统一用「你」
避免
按钮：「进行保存操作」「确定」
反馈：「操作成功」
空状态：「暂无数据」（无行动引导）
人称：「您 / 你 / 亲」混用

9国际化（i18n）

项约定
文本取用经 i18n key 取用，禁止模板硬编码中文
key 命名模块.场景.键，如 common.button.save
文案预留英文比中文长 20%–40%，容器留弹性宽度
RTL令牌以逻辑属性表达（margin-inline），便于扩展

11代码约定

令牌文件

src/styles/tokens/ 按 colors / typography / spacing / motion / z-index / glass 拆分

CSS 变量命名

前缀 --wb-，如 --wb-color-primary、--wb-glass-bg

图标组件

封装 <AppIcon name="search" />，禁止散落 SVG 路径

禁止硬编码

色值 / 字号 / 间距 / 圆角 / 阴影 / z-index 一律引用令牌，CR 拦截
